# nexa-digital

Requires Python 3.13 or newer. Standard library only; no pip install, account, API key or monthly subscription.
Run from this folder:

```powershell
py -m unittest discover -s tests -v
py digital.py --topic "Weekly focus" --audience "Busy beginners"
```

Results are in output/. See ../WINDOWS-SETUP.md for setup and GitHub automation.
Upload this folder's CONTENTS, including .github, to the root of its own GitHub repository.
The weekly workflow is an independent fresh run, not a persistent agent or account.
